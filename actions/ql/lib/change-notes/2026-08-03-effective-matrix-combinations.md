* Matrix job synchronization now projects static matrices onto only the axes referenced by step conditions, `continue-on-error` expressions, and reusable-workflow arguments, without a fixed combination cutoff. Ordered `include` values and definite `exclude` effects are retained in each projection, while dynamic matrices use a conservative wildcard. Job conditions similarly retain exact statuses only for referenced `needs.<job>.result` values and relevant shared prerequisites, summarizing all other prerequisites without fixed direct or transitive limits. Matrix calls to reusable workflows enter and complete the callee per projected combination before status fan-in, pass nested effective values through typed inputs, and expose statically known per-invocation outputs through `MatrixJobInstance.getReusableWorkflowOutputValue()`.
